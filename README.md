## 🚀 Overview

**[UdaraDirect.car]** is built to handle the complexities of a modern car rental business. It provides a seamless reservation experience for customers while giving administrators and fleet managers powerful tools to track vehicle availability, manage bookings, and analyze revenue in real-time.

## ✨ Key Features

### 👤 Customer Experience
- **Smart Catalog:** Browse vehicles by brand, model, fuel type, and dynamic pricing.
- **Real-Time Booking:** Prevent double-bookings with instant availability checks.
- **Secure Access:** End-to-end secure registration and JWT-based authentication.
- **Self-Service Portal:** Manage active reservations, view history, and handle cancellations effortlessly.

### 🛡️ Admin & Fleet Management
- **Centralized Dashboard:** Get a bird's-eye view of fleet status (Available, Rented, Maintenance).
- **Inventory Control:** Add, update, or decommission vehicles on the fly.
- **Booking Moderation:** Review, approve, or decline customer reservation requests.
- **Automated Maintenance:** Block out calendars automatically for scheduled vehicle servicing.

## 📊 Business Intelligence (MIS)

The system is equipped with automated reporting tools to drive data-driven decisions:
* 📈 **Revenue Analytics:** Track daily and monthly earnings breakdowns.
* 🚙 **Fleet Utilization:** Identify top-performing vehicles vs. underutilized assets.
* 📅 **Booking History:** Audit logs and historical data within custom timeframes.

## 👥 Access Control

The application uses Role-Based Access Control (RBAC) to ensure security and proper delegation:
1. **Customer:** Browse, book, and manage personal profiles.
2. **Admin:** Full system control, inventory management, and reporting.
3. **Fleet Manager:** Focused access to vehicle health, maintenance, and availability.
4. **Payment Manager:** Dedicated role for verifying transactions and financial records.
